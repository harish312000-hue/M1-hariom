# M1 HARIOM 0.5 — Insights

This milestone adds a local-first analytics dashboard with:
- Day/week/month/3-month/6-month/year filters
- Wake-up success and average wake time
- Snooze analytics
- Challenge performance
- Current and best wake streaks
- No-snooze and early-bird streaks
- M1 Discipline Score
- Daily performance chart
- Personal records
- Achievement milestones

Analytics are derived from locally stored alarm events. The UI uses the selected green analytics treatment; the rest of the app retains the M1 dark/orange visual direction.
